DshShell 一键安装

安卓手机 · 不需要翻墙 · 不需要电脑 · 全程约 5～15 分钟

1装 Termux（必须先做这步）

正在识别你的机型…
下完点开安装。系统会问「允许安装未知应用」→ 选允许。
装好后先别急着打开，回到本页做第 2 步。
下不动 / 想换个来源 / 想手动选版本
方式一（推荐 · 国内直连，不用梯子） 夸克网盘下载 Termux
手机浏览器打开 → 找到 termux-app_v0.118.3+github-debug_arm64-v8a.apk → 下载。
方式二（GitHub 直链 · 需要能访问 GitHub） github.com/termux/termux-app/releases ↑ 加速打开
大多数手机（近几年 64 位机型）用 arm64-v8a；
很老的机型用 armeabi-v7a；
拿不准就选 universal（全兼容，但 112MB）。

2打开 Termux，授权存储

在 Termux 里长按屏幕 → Paste（粘贴），然后回车：
termux-setup-storage
弹出权限窗口 → 点允许。这一步不做，安装包会落在一个你打不开的地方。
不会粘贴？看这里
Termux 里长按屏幕空白处会弹出菜单，点 Paste 就是粘贴。
如果剪贴板里是上面那行命令，粘贴后按回车即可。
也可以自己在 Termux 里用键盘一个字母一个字母敲：termux-setup-storage

3粘贴这一条命令，剩下的全自动

在 Termux 里粘贴并按回车（下面这行会自动换源，不用管网络）：
它会自动完成：下载安装包 → 校验完整性 → 装依赖 → 给 DSH 打安卓修复补丁 → 编译蓝牙原生模块 → 安装移动端适配插件 → 启动服务。
中途会问你一次要「浏览器模式」还是「本机 APK 版」，按回车用默认的浏览器模式即可。

4装完之后

终端会打印一个网址
（形如 http://127.0.0.1:3080/?token=…）。
用手机浏览器打开它就能用了，建议加到桌面。
建议再做两件事，否则小米/华为等系统会把它清理掉：
· 设置 → 应用 → Termux → 省电策略 → 无限制
· 最近任务里给 Termux 加锁（下拉图标）
遇到问题：再跑一次第 3 步那条命令即可（安装器是幂等的，不会重复装）。
